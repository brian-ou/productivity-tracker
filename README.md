# Academic Productivity Dashboard (In Progress)

A web-based productivity tool designed to help students centralize academic schedules and deadlines by integrating Google Calendar and Canvas.

This project is an active work-in-progress focused on building clean data ingestion pipelines and a simple, modular UI for planning and visualization.

## Current Focus
- Designing the application architecture using Next.js
- Implementing core frontend layout and routing
- Preparing OAuth-based integration with external APIs (Google Calendar, Canvas)

## Planned Features
- Secure authentication via OAuth
- Aggregation of academic events and deadlines
- Visual dashboard for schedules and task planning

## Tech Stack
- Next.js (React, App Router)
- TypeScript
- Tailwind CSS (if applicable)
- Deployed via Vercel (planned)

## Status
This project is under active development. Core structure and UI are implemented; API integration and data handling are in progress.
